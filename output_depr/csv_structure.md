# Структура выходных CSV

Папка: `output_depr`.

## `af_summary.csv` (6 строк)
Итоги индекса Алкайр–Фостера: строка = год × порог k

| Столбец | Что хранится |
|---|---|
| year | год |
| N | оценённых ДХ |
| k | порог бедности |
| H | доля бедных |
| A | интенсивность (средний счёт у бедных) |
| M0 | индекс H·A |
| n_indicators | критериев в индексе |

## `indicator_prevalence.csv` (56 строк)
Распространённость критериев: строка = критерий (индекс — код dep_*)

| Столбец | Что хранится |
|---|---|
| 2023/2024 | доля депривированных среди определённых |
| coverage_2023/2024 | доля ДХ, у которых критерий определён |
| label | подпись |
| in_index | входит ли в индекс |

## `indicator_contributions.csv` (108 строк)
Вклад индикаторов в M0 при основном k: строка = индикатор × год

| Столбец | Что хранится |
|---|---|
| (индекс) | код dep_* |
| censored_H | доля ДХ: бедны и депривированы по критерию |
| weight | вес индикатора |
| вклад в M0 | доля M0 |
| year | год |
| dimension | номер измерения 1–8 |

## `household_af_scores.csv` (24 000 строк)
Оценки по домохозяйствам: строка = ДХ × год

| Столбец | Что хранится |
|---|---|
| year | год |
| HOUSEHOLD_ID | ID ДХ (уникален внутри года) |
| dep_* | бинарные критерии 1/0/пусто (dep_7_5 ещё 0.5) |
| x_* | непрерывные и вспомогательные (ниже) |
| TE | код региона |
| K | 1 город, 2 село |
| af_score | взвешенная доля депривации 0–1 |
| af_poor | бедно ли при k=1/3 (пусто — не оценено) |

## `af_by_groups.csv` (74 строк)
Индекс по группам (8.3, 8.4, 9.1, 7.7): строка = группа × значение × год

| Столбец | Что хранится |
|---|---|
| group | разбивка |
| value | значение |
| year | год |
| N | ДХ |
| H | доля бедных |
| A | интенсивность |
| M0 | индекс |
